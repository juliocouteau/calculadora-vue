🧮 Calculadora Aritmética Reativa
Uma calculadora moderna desenvolvida com Vue.js que realiza cálculos em tempo real através de reatividade.

💻 Sobre o Projeto
Este projeto foi desenvolvido para praticar os conceitos fundamentais do ecossistema Vue.js, especificamente o two-way data binding e as propriedades computadas. A aplicação permite que o utilizador insira dois números, escolha uma operação aritmética e visualize o resultado instantaneamente, sem a necessidade de clicar em botões de "calcular" ou recarregar a página.

⚙️ Funcionalidades
[x] Cálculo em Tempo Real: O resultado é atualizado automaticamente ao alterar qualquer valor ou operação.

[x] Operações Básicas: Soma, Subtração, Multiplicação e Divisão.

[x] Interface Responsiva: Design adaptável para diferentes tamanhos de ecrã.

[x] Tratamento de Dados: Filtros para garantir que apenas números sejam processados.

🚀 Tecnologias Utilizadas
Vue.js 3: Framework principal para a lógica e reatividade.

JavaScript (ES6+): Manipulação da lógica aritmética.

HTML5 & CSS3: Estrutura e estilização da interface.

Google Fonts: Tipografia personalizada.
